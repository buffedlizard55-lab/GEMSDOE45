Prize structure & limits (official rules PDF / problem page)

  • Initial round $50,000 — top 5, $10,000 each, scored on a private set of new faults labeled before the competition.
  • Final round $250,000 — top 5 ($100k/$70k/$40k/$25k/$15k) re-scored against the expanded label set that includes faults experts verify from all submissions.
  • Up to 3 submissions per week; you must finally select one submission for both rounds (can't see private scores first).
  • Generative-AI disclosure: if you used generative AI, state its extent in the narrative (rules §3.2). This submission was produced with autonomous agent assistance; the algorithm, data provenance and validation are fully documented on the Method page.
Before you spend a slot — read this. The live score cannot be computed here (hidden test labels are not public). We validate on a proxy holdout (public catalogue) and on uniqueness vs prior submissions. A sibling project measured near-zero correlation between such proxy scores and the live leaderboard (Spearman ρ≈0.09, IRR-01), so the proxy is a relative instrument only. We publish it for transparency, not as a live-score prediction. The novelty here targets the unmapped geothermal-conduit population the competition is about.
